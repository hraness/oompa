# Contents

- `contract.ts` binds the private child descriptor, three fixed daemon stages and exact nonce-only prompts.
- `state.ts` and `state.test.ts` reduce the bounded restart observations without granting native authority.
- `command-intent.ts` snapshots six fixed mutation/import commands; `custody.ts` persists their generation-bound intent and the three child scopes before dispatch.
- `daemon-child.ts` runs the ordinary daemon only in a fresh live-acceptance installation; `daemon-process.ts` owns its exact handle, controller pipe, cancellation and stream joins.
- `process-observer.ts` observes the actual Claude runtime and process, records attempted replay before refusing it and withholds only the second generation's fixed fulfilled-write acknowledgment.
- `process-status.ts` validates and copies the three bounded acceptance counters for the explicitly guarded daemon status field; its tests reject unknown fields and invalid counts.
- `run.ts` owns fresh authentication, seed-thread creation and the three-generation parent sequence. Its native invocation remains separately gated; ordinary tests admit no native authority.

# Guidelines

- Use only fresh short `oompa-md-` roots and the distinct daemon owner family. Never reuse account/session qualification roots or personal state.
- Keep the public entry fixed to actual source admission, owner authentication, production daemon dispatch and three joined daemon generations. Expose no injected runtime, process, root, operation or acknowledgment-loss flag to a native public entry.
- Persist operation intent before dispatch. Any unknown operation or missing physical collection retains its exact roots and receipt; never replay it or infer no effect from an error.
- The one deliberate missing acknowledgment follows actual local stdin fulfillment. It establishes no remote provider acknowledgment or completed effect.
- Count attempted user writes, including refused attempts. The third generation must preserve the original ambiguous input and attempt no new user write.
- Keep acceptance nonce rules, counters, status bounds and deliberate acknowledgment loss in this repository-only directory. The packaged observation adapter owns no qualification policy, and the CLI copies only the three declared status fields from the guarded hook.
- Keep physical child/stream/observer collection separate from operation failure. Root collection is not a claim about unobserved descendants.
- Keep credentials, raw frames, provider output and personal paths out of public summaries. Private receipts remain bounded and owned.
- Ordinary tests are pure or use inert adapters. Native/process/SQLite and authenticated execution require their separately owned acceptance invocation. This proof cannot enable managed Mac policy or production defaults.
